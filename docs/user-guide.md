# คู่มือการใช้งานระบบวางบิลและภาษีฟรีแลนซ์ (User Manual)

คู่มือนี้แนะนำขั้นตอนการใช้งานระบบ Multi-Income Billing สำหรับฟรีแลนซ์และคนทำงานรายได้หลายทาง ตั้งแต่การออกบิลไปจนถึงการยื่นภาษีประจำปี

---

## 1. การตั้งค่าข้อมูลผู้รับเงินครั้งแรก (Profile Setup)

ก่อนเริ่มออกบิล ให้เข้าไปที่แท็บ **"โปรไฟล์ผู้รับเงิน"**:

1. กรอก **ชื่อ-นามสกุล** หรือชื่อร้านค้า
2. กรอก **เลขประจำตัวประชาชน / ผู้เสียภาษี (13 หลัก)**
3. กรอก **ที่อยู่** สำหรับให้ลูกค้าจัดส่งเอกสารใบ 50 ทวิ
4. กรอก **เบอร์พร้อมเพย์ (PromptPay)** และ **ข้อมูลบัญชีธนาคาร**
5. กดปุ่ม **"บันทึกข้อมูลโปรไฟล์"**

ข้อมูลนี้จะถูกนำไปสร้างหัวใบแจ้งหนี้และสร้าง QR Code สำหรับรับเงินโดยอัตโนมัติ

---

## 2. ขั้นตอนการออกใบแจ้งหนี้ / ใบวางบิลใหม่

1. คลิกปุ่ม **"ออกบิลใหม่"** (หรือกดปุ่มลัด `⌘ + N` บนคีย์บอร์ด)
2. ตรวจสอบ **เลขที่บิล** และ **วันที่ครบกำหนดชำระ**
3. เลือก **ประเภทเงินได้ (ภ.ง.ด. 90)** ให้ตรงกับลักษณะงาน:
   * **40(2) จ้างทำของ:** งานฟรีแลนซ์ทั่วไป รับจ้างผลิตงาน เขียนโค้ด ออกแบบ
   * **40(6) วิชาชีพอิสระ:** งานที่มีใบประกอบวิชาชีพเฉพาะ เช่น บัญชี ทนายความ วิศวกรรม
   * **40(8) คอนเทนต์ / การค้า:** รับสปอนเซอร์รีวิวสินค้า ค้าขายออนไลน์
4. กรอกชื่อและที่อยู่ของ **ลูกค้า / ผู้ว่าจ้าง**
5. ระบุรายการงาน จำนวน และราคาต่อหน่วย (ระบบจะคำนวณหักภาษี 3% และยอดเงินสุทธิให้ทันที)
6. คลิก **"บันทึกใบแจ้งหนี้"**

---

## 3. การส่งบิลให้ลูกค้าทาง LINE

เมื่อบันทึกบิลแล้ว คุณสามารถส่งข้อมูลให้ลูกค้าได้ 2 วิธี:

### วิธีที่ 1: คัดลอกข้อความสรุปส่งทาง LINE
คลิกปุ่ม **"คัดลอกส่ง LINE"** แล้วนำข้อความไปวางในแชท LINE ของลูกค้า ข้อความจะระบุยอดสุทธิ เลขบัญชี และแนบลิงก์สำหรับเปิดดูบิลออนไลน์ให้ลูกค้าอัตโนมัติ

### วิธีที่ 2: พิมพ์หรือส่งเป็นไฟล์ PDF
คลิกปุ่ม **"พิมพ์ / PDF"** เบราว์เซอร์จะเปิดหน้าต่างสั่งพิมพ์ ให้เลือกบันทึกเป็น PDF (`Save as PDF`) เพื่อส่งไฟล์ให้ฝ่ายบัญชีของลูกค้า

---

## 4. สิ่งที่ลูกค้าจะเห็นเมื่อเปิดลิงก์ออนไลน์

เมื่อลูกค้าเปิดลิงก์ที่ส่งให้ผ่าน LINE ลูกค้าจะเห็น:
* ใบแจ้งหนี้ฉบับเต็ม พร้อมแจกแจงยอดก่อนหักและยอดหักภาษี 3%
* **QR Code PromptPay** ที่ระบุยอดเงินสุทธิตรงเป๊ะ ลูกค้าสามารถสแกนจ่ายผ่านแอปธนาคารได้ทันที
* ปุ่มสำหรับ **คัดลอกเลขที่บัญชี** หรือ **คัดลอกเบอร์พร้อมเพย์** เพื่อนำไปวางในแอปธนาคาร
* ลูกค้าไม่จำเป็นต้องสมัครสมาชิกหรือล็อกอินใดๆ ทั้งสิ้น

---

## 5. การบันทึกสลิปและใบหัก ณ ที่จ่าย (50 ทวิ)

เมื่อลูกค้าโอนเงินและส่งหลักฐานกลับมา:

1. ในตารางรายการบิล ให้คลิกไอคอน **คลิปหนีบกระดาษ (แนบหลักฐาน)**
2. คลิกเลือกรูปภาพ **สลิปโอนเงิน** (ระบบจะเปลี่ยนสถานะบิลเป็นชำระแล้วอัตโนมัติ)
3. เมื่อได้รับเอกสารใบหักภาษี 3% ให้ถ่ายรูปแล้วคลิกอัปโหลดในช่อง **รูปใบ 50 ทวิ**
4. ระบบจะบีบอัดรูปภาพให้อัตโนมัติเพื่อไม่ให้เปลืองพื้นที่จัดเก็บในเครื่อง

---

## 6. การสรุปยอดและเตรียมตัวยื่นภาษี ภ.ง.ด. 90

เมื่อถึงช่วงต้นปี (มกราคม - มีนาคม) ที่ต้องยื่นแบบภาษีเงินได้บุคคลธรรมดา:

1. คลิกเข้าไปที่แท็บ **"สรุปภาษี ภ.ง.ด. 90"**
2. ตรวจสอบ **รายรับรวมแยกตามหมวด** 40(2), 40(6), 40(8) เพื่อนำตัวเลขไปกรอกในระบบ e-Filing ของกรมสรรพากร
3. นำยอด **ภาษีถูกหัก 3% สะสม** ไปกรอกในช่อง "ภาษีเงินได้หัก ณ ที่จ่าย" เพื่อขอคืนเงินภาษีหรือหักลบยอดภาษีที่ต้องจ่ายเพิ่ม
4. คลิกปุ่ม **"Export Excel"** เพื่อดาวน์โหลดไฟล์สรุปตัวเลขและรายการบิลทั้งหมดเก็บไว้เป็นหลักฐาน

---

## 7. การสำรองข้อมูล (Backup & Restore)

เนื่องจากระบบเก็บข้อมูลไว้ในเครื่องของคุณเพื่อความเป็นส่วนตัวสูงสุด:

* **ก่อนล้างประวัติเบราว์เซอร์หรือเมื่อต้องการย้ายเครื่อง:** ให้เข้าไปที่แท็บ **"โปรไฟล์ผู้รับเงิน"** แล้วคลิกปุ่ม **"ดาวน์โหลดไฟล์ Backup (.json)"**
* **เมื่อต้องการนำข้อมูลกลับมาใช้ในเครื่องใหม่:** ให้เปิดเว็บแล้วคลิกปุ่ม **"เลือกไฟล์สำรองเพื่อกู้คืน"** ในแท็บโปรไฟล์ ข้อมูลบิลและรูปภาพทั้งหมดจะกลับมาแสดงผลทันที
