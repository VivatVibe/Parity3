# Thai Multi-Income Billing & Tax Tracker

เว็บแอปพลิเคชันสำหรับออกใบวางบิล คำนวณภาษีหัก ณ ที่จ่าย 3% และสรุปยอดสะสมแยกหมวด ภ.ง.ด. 90 ออกแบบมาโดยเฉพาะสำหรับคนทำงานรายได้หลายทางและฟรีแลนซ์ในประเทศไทย

---

## ฟังก์ชันการทำงานหลัก

* **สร้างใบแจ้งหนี้ / ใบวางบิล:** สร้างเอกสารมาตรฐานไทย แสดงยอดเงินตัวอักษรภาษาไทย และรองรับการพิมพ์หรือเซฟเป็น PDF
* **QR Code PromptPay อัตโนมัติ:** สร้าง Thai QR Payment มาตรฐาน EMVCo พร้อมระบุยอดเงินสุทธิที่ต้องชำระทันที
* **คำนวณภาษีหัก ณ ที่จ่าย 3%:** แสดงยอดก่อนหัก ยอดภาษีถูกหัก และยอดสุทธิอย่างชัดเจน
* **ติดตามใบ 50 ทวิ:** สลับสถานะติดตามหนังสือรับรองการหัก ณ ที่จ่าย พร้อมแนบรูปถ่ายใบ 50 ทวิ และสลิปการโอนเงิน
* **สรุปภาษี ภ.ง.ด. 90:** จัดหมวดหมู่รายได้ 40(2), 40(6), 40(8) และคำนวณเครดิตภาษีสะสมเพื่อใช้ยื่นภาษีประจำปี
* **ส่งออกข้อมูล (Export CSV):** รองรับการเปิดด้วย Microsoft Excel ด้วยรหัสภาษาไทย UTF-8 BOM
* **สำรองและกู้คืนข้อมูล (Backup & Restore JSON):** เก็บข้อมูลลงไฟล์ JSON เพื่อย้ายเครื่องหรือสำรองข้อมูลได้อย่างปลอดภัย

## การติดตั้งและเริ่มใช้งานในเครื่อง

```bash
# ติดตั้ง dependencies
npm install

# รันชุดทดสอบความถูกต้องของระบบ
npm test

# เปิดเซิร์ฟเวอร์สำหรับพัฒนา
npm run dev

# คอมไพล์โปรเจกต์สำหรับ Production
npm run build
```
